# Security and privacy reports

For incorrect or sensitive listing information, or a possible data breach, contact the operator via the email listed in the privacy notice. Do not post personal data in public GitHub issues. Include the listing reference shown in the source details. Requests are assessed and qualifying listings can be excluded via assets/listing-suppression.js and a new release. Check both sites and notify upstream Overture separately. GDPR requests are generally answered within one month, subject to legal exceptions.
